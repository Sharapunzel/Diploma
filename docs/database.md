# Тестовая PostgreSQL и миграции

Эта инструкция нужна оператору и проверяющему при запуске миграций, тестов и восстановлении базы.

`diploma_db` — база разработки. Не запускайте на ней тесты, сброс с удалением данных или откаты миграций. Режим `--shared` полного backend-набора использует только `diploma_test`; её данные временные. Скрипт проверяет имя и пересоздаёт только эту тестовую базу, а после прогона оставляет пустую схему на текущей ревизии Alembic. Режим `--temporary` создаёт отдельную базу с уникальным именем и удаляет её после прогона. Не запускайте два набора одновременно на общей `diploma_test`.

Из корня репозитория в PowerShell или Linux shell запустите изолированный полный профиль. Он сам создаёт тестовую БД и синтетический пароль, проверяет Kafka и удаляет ресурсы после прогона:

```shell
python scripts/agent_test_profiles.py kafka-integration
```

Ожидаются успешный pytest, сверка Kafka metadata и нулевой код завершения после очистки временного проекта. Если профиль упал на подключении, проверьте его вывод по DNS/маршруту, advertised listener, TLS/CA, SCRAM, ACL и PostgreSQL; не перенаправляйте его на `diploma_db`.

Для независимого ревью скрипт `backend/scripts/run_tests.py --temporary` создаёт уникальную временную БД и удаляет её после завершения. Прямой запуск требует заранее заданного `TEST_DATABASE_URL` с доступом к тестовому PostgreSQL; постоянный профиль выше выполняет эту подготовку. Если отмеченная
ревизия БД структурно не соответствует миграциям, не исправляйте ревизию вручную и
не запускайте набор поверх неё: штатный скрипт пересоздаёт только `diploma_test`.

При развёртывании миграции запускает одноразовый Compose-сервис `migrate` до API. Схему
меняют только Alembic-миграции; `create_all()` не используется. Для ручного запуска
задайте `DATABASE_URL` именно целевой БД и выполните из `backend/`:

```shell
python -m alembic upgrade head
python -m alembic current
```

Никогда не запускайте `alembic downgrade` на `diploma_db`. Для локальной разработки
используйте корневой [README](../README.md) и dev override Compose.
