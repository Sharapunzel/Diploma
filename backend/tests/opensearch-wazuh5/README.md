# Проверка внешнего индексера Wazuh 5

Этот документ нужен разработчику при проверке совместимости внешнего пути событий. Для штатной приёмки из корня репозитория запускайте постоянный изолированный профиль:

```shell
python scripts/agent_test_profiles.py external-end-to-end
```

Профиль поднимает production-состав приложения и настоящий `wazuh/wazuh-indexer:5.0.0-beta5`, закреплённый по digest в `scripts/agent_test_profiles.py`. Он создаёт синтетические секреты, CA и данные в `.harness/runs/<run-id>`, проверяет живой backend и UI через HTTPS proxy, затем удаляет созданные ресурсы. Для проверки Compose без запуска используйте `--check-only`. Требования к Docker и очистке описаны в [профилях](../../../docs/agent-test-profiles.md).

Скрипты этого каталога используются профилем: `generate_certs.py` выпускает тестовый CA и сертификат индексера, `bootstrap_readonly.py` создаёт роль чтения, `seed_synthetic.py` загружает данные, `smoke_indexer.py` проверяет HTTPS, mappings, PIT и запрет записи. Переменные `WAZUH_TEST_RUNTIME` и `WAZUH_TEST_BASE_URL` указывают на изолированный каталог и опубликованный адрес текущего прогона. Контейнер API обращается к индексеру по внутреннему имени `https://indexer:9200`; адрес хоста ему не подходит.

Набор содержит индекс из 24 документов, семейство индексов из 128 и два семейства потоков из 144 документов. В нём есть совпадающее время для проверки устойчивой сортировки, ECS-подобные и `wazuh.*` поля. Роль читателя разрешает чтение документов, mappings и жизненный цикл PIT только для `task12-*` и `wazuh-findings-v5-*`.

Данные имеют форму WCS в настоящем индексере Wazuh 5 beta5, но создаются тестовым скриптом и упрощёнными mappings. Профиль не запускает Wazuh Manager и не проверяет выпуск findings его конвейером. Каталог полей показывает лишь безопасные операции согласно mappings: `exists`, `not_exists`, `neq` и общие числовые/датовые диапазоны для внешнего источника не предлагаются; время ECS `@timestamp` доступно для ограничения периода. `contains` и `ends_with` требуют не менее трёх символов.
